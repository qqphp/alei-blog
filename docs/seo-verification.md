# 上线前 SEO 本地验收记录

日期：2026-10-07。对象：当前 Vinext 1.0.1 / PostgreSQL 博客的本地生产构建。

## 已完成的功能

- 网站设置新增 SEO 标签页：沿用首页 `site.title`、`site.description`，新增默认分享图与图片说明；正式地址和有效收录状态由环境提供并只读展示。
- 文章搜索展示支持可选标题、描述与预览。空值回退到标题、摘要或 Markdown 纯文本；自动描述按 160 个 Unicode 字符截取，独立描述保留内容。
- 新增 `0026_article_seo.sql`，增加两个 `NOT NULL DEFAULT ''` 列。旧创建请求省略字段按空值处理，旧更新请求省略字段保留已有覆盖；显式空字符串清除覆盖。
- 所有 15 个公开栏目输出独立 metadata；文章、项目输出自己的 canonical、Open Graph、Twitter 和对应结构化数据。品牌后缀读取当前站点名称。
- 写作和项目支持服务端分页及真实链接；文章搜索保持 250ms 防抖。项目详情的主内容独立于侧栏筛选和页码上下文。
- 动态 robots 和 sitemap 遵循收录开关；sitemap 读取全部已发布记录的轻量字段，真实更新时间作为 lastmod，不读取文章或项目完整正文。
- WebSite、BlogPosting、BreadcrumbList JSON-LD 与可见内容对应，转义 script 边界字符，不补造首次发布时间或图片尺寸。
- 修复生产 Node 图片优化端点读取 CMS 上传图片时的 404，保持响应尺寸和 WebP 压缩；调整首页首张封面优先级及项目图片 sizes。
- 禁用流式元信息，确保标签在初始 HTML 的 `<head>`；补充 Vinext 对缺少 User-Agent 请求的兼容修补。检查严格限定在 head 内，避免只因正文尾部存在标签就误判通过。

## 浏览器与性能

`npm run test:seo:browser` 使用现有 Edge/Chromium 的无头浏览器，在本地生产服务上检查真实已发布内容。桌面 1440×1000、DPR 1；移动 390×844、DPR 2。无网络和 CPU 节流，每页加载后观察 3 秒，再滚动检查所有懒加载图片。

| 页面 | 桌面 LCP | 移动 LCP | CLS |
| --- | --- | --- | --- |
| 首页 | 1,000 ms | 312 ms | 均为 0 |
| 文章 | 264 ms | 468 ms | 均为 0 |
| 项目 | 572 ms | 444 ms | 均为 0 |

最终独立复测的六组抽查均达到本地实验室目标 LCP ≤ 2.5 秒、CLS ≤ 0.1，未发现横向溢出、运行时异常或破图。桌面和移动端搜索、防抖后 URL 更新、刷新、分类链接、前进后退、项目链接和标题同步均通过；文章与项目面包屑在移动端和桌面均可见。

保留测量波动：与数据库回归同时运行的一次桌面首页测量为 LCP 3,152 ms，超过目标；当时没有确认并发工作的影响，因此不能将其直接归因于本机负载。最终独立复测首页为 1,000 ms，TTFB 583 ms，包含阻塞元信息配置。单次本地达标不保证正式服务器在冷启动或负载下达标，部署时应独立重复测量并关注分位数。

截图及每张图片的显示尺寸、实际尺寸、传输量记录在 `outputs/seo-browser/`；完整数据为 `metrics.json`。目录在 Git 忽略范围内。以一张实际封面为例，原始 WebP 为 104,430 字节，640px 优化响应约 26,616 字节。

这些结果是单台本地设备、无节流的实验室抽查，不代表正式域名的真实用户 Core Web Vitals，也没有验证移动运营商网络、CDN 或生产服务器负载。上线后继续采集 LCP、CLS 与 INP。
